# FDMX Browser Extension Privacy Policy

Last updated: 2026-11-11

FDMX Download Manager is a companion extension for the FDMX desktop application.

## Data handling
- The extension does not collect analytics, browsing history, account information, or personal data.
- The extension does not send browsing data to FDMX servers or other remote services.
- When you choose an extension command, the selected HTTP/HTTPS URL is sent to the FDMX desktop application through a local connection to 127.0.0.1:38471.
- The URL is processed by the desktop application on your device. The extension does not transmit it to the extension developer.

## Permissions
- **contextMenus** adds commands to the browser's context menu.
- **activeTab** and **tabs** identify the current tab after you interact with the extension.
- **scripting** reads direct video/source URLs from the current page only when you press the media scan button.
- **Host access to 127.0.0.1** allows communication with the locally running FDMX desktop bridge.
