# GNS Downloader 6.52

## Highlights

- GitHub Actions artifact links can use the active Chrome or Firefox GitHub browser session through the companion browser extension.
- The browser performs the authenticated artifact redirect and passes only the short-lived signed download URL to the desktop app.
- The desktop app keeps the original GitHub artifact page as the task/history URL and holds the temporary signed URL in memory only; it is excluded from task snapshots and history.
- Browser cookies are never read, exported, logged, or persisted by GNS Downloader or its extensions.
- Existing anonymous access, GitHub CLI credentials, and deferred manual-token fallback remain available when browser-session resolution is unavailable.
- Browser extensions are versioned separately as 1.1.0 and produce new versioned ZIP/XPI packages without replacing earlier files.
- Windows Setup, Windows portable ZIP and Ubuntu/Debian DEB packages are built and smoke-tested by GitHub Actions.
- Release packages are checked against the 50 MiB size limit.

## Downloads

- Windows installer: GNS-Downloader-Setup.exe
- Windows portable: GNS-Downloader-Portable-Windows-x64.zip
- Ubuntu/Debian package: GNS-Downloader-6.52-amd64.deb

The v6.52 release workflow runs offline regression tests, builds both Windows and Linux packages, smoke-tests installation/launch, and publishes the official GitHub Release only after successful builds.
