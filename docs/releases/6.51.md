# GNS Downloader 6.51

## Highlights

- GitHub Actions artifact downloads try anonymous access first; a GitHub token is requested only after an authentication failure.
- Existing GitHub CLI credentials are reused silently when available. Manually entered tokens remain in memory only and are excluded from task/history persistence.
- GitHub authorization headers are stripped on cross-origin redirects to object storage.
- Completed downloads are sorted newest-first while active and queued task order remains stable.
- The first Start action begins the download automatically after metadata is resolved.
- Windows Setup, Windows portable ZIP and Ubuntu/Debian DEB packages are built and smoke-tested by GitHub Actions.
- Release packages are checked against the 50 MiB size limit.

## Downloads

- Windows installer: GNS-Downloader-Setup.exe
- Windows portable: GNS-Downloader-Portable-Windows-x64.zip
- Ubuntu/Debian package: GNS-Downloader-6.51-amd64.deb

The v6.51 release workflow runs offline regression tests, builds both Windows and Linux packages, smoke-tests installation/launch, and publishes the official GitHub Release only after successful builds.
