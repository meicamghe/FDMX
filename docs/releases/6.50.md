# GNS Downloader 6.50

## Highlights

- Carries forward the v6.48 YouTube video/audio download integration, including yt-dlp, FFmpeg support for best-quality video merging, and HTTP/HTTPS/SOCKS proxy handling.
- Carries forward the download-worker reliability fixes and regression coverage for pause, resume, cancellation, partial-file retention, and existing-file conflict choices.
- Carries forward the stable-release updater improvements: numeric version selection, release-note handling, and downloaded-installer integrity checks.
- Updates the maintained application version to 6.50.

## Validation

- Offline YouTube regression tests are run by GitHub Actions.
- Windows and Ubuntu package smoke builds verify the frozen application and bundled YouTube/FFmpeg/proxy dependencies.
- Live YouTube downloads, live proxy endpoints, and manual GUI behavior must be validated separately; CI smoke tests do not claim those network scenarios.

This file is the 6.50 release-note draft. The version is not an official public release until the v6.50 tag is built and published.
