# GNS Downloader 6.50

## Highlights

- YouTube video and audio downloads through yt-dlp, with FFmpeg support for best-quality video merging.
- HTTP, HTTPS, SOCKS4, SOCKS4a, SOCKS5 and SOCKS5h proxy support.
- More reliable download pause, resume and cancellation handling, including resumable partial files.
- Existing-file conflict choices: replace, save as new, or open the existing file.
- Stable-release updater improvements, including numeric version selection and downloaded-installer integrity checks.

## Downloads

- Windows installer: GNS-Downloader-Setup.exe
- Windows portable: GNS-Downloader-Portable-Windows-x64.zip
- Ubuntu/Debian package: GNS-Downloader-6.50-amd64.deb

The Windows and Linux release assets are built and smoke-tested by the v6.50 release workflow.
