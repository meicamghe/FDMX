# GNS Downloader 6.42

## Highlights

- Fixed escaped newline handling in release notes shown by the in-app updater.
- Added meaningful fallback release notes when a GitHub release has an empty description.
- Fixed the Windows installer icon path so the generated icon is resolved reliably.
- Carries forward the 6.41 download engine improvements: configurable 1–16 parts and safer resume behavior.
