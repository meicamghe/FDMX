# GNS Downloader 6.53

## Highlights

- Automatic browser-to-desktop download handoff through the registered `gnsdownloader://` protocol. On supported installed builds, the protocol launches the desktop app when it is not already running and queues the submitted URL.
- Browser companion extension 1.3.0 for Firefox and Chrome, including context-menu download handoff and direct-media detection.
- YouTube media picker integration: the extension requests available video resolutions and audio bitrates from the desktop `yt-dlp` engine, including audio-only options.
- Added **Tools → Install browser extensions…** guidance in the desktop application.
- Improved YouTube format selection and fallback behavior; updated offline regression coverage for the current media selection implementation.
- GitHub artifact downloads can reuse the browser's authenticated session without reading or exporting cookies. Short-lived signed download URLs are kept out of task snapshots and history.
- Windows Setup, Windows Portable and Ubuntu/Debian DEB packages are built and smoke-tested by CI. Each application package is kept below 50 MiB.

## Validation

The release build completed the Windows packaging and launch smoke test, Linux DEB packaging and launcher smoke test, browser-extension packaging, and offline YouTube regression checks. These automated checks do not replace live network testing against every supported media provider or manual testing on every desktop environment.
