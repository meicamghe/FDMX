# راهنمای فارسی FDMX

این فایل راهنمای نصب و استفاده از FDMX به زبان فارسی است. برای معرفی کلی پروژه و راهنمای انگلیسی، فایل [README.md](../README.md) را ببینید.

## FDMX چیست؟

FDMX یک دانلودمنیجر دسکتاپ نوشته‌شده با Python و PySide6 است. این پروژه شامل نسخه اصلی ویندوز، یک نسخه با ظاهر الهام‌گرفته از Ubuntu و افزونه‌های مرورگر Chrome و Firefox است.

## انتخاب نسخه

- **ویندوز:** نسخه `FDMX_v6_11.py` آخرین نسخه‌ای است که در روند توسعه توسط کاربر تست و تأیید شده است.
- **Ubuntu Theme:** فایل `ubuntu.py` ظاهر بنفش تیره و نارنجی Ubuntu را ارائه می‌کند؛ این نسخه هنوز نیازمند تست روی سیستم‌های مختلف لینوکس است.
- نسخه‌های قدیمی‌تر با هدف حفظ تاریخچه توسعه در مخزن نگهداری شده‌اند.

## نصب در ویندوز 10 و 11

### ۱. نصب Python

Python نسخه 3.10 یا جدیدتر را از [سایت رسمی Python](https://www.python.org/downloads/) نصب کنید. هنگام نصب گزینه **Add Python to PATH** را فعال کنید.

### ۲. دریافت پروژه

در PowerShell یا CMD اجرا کنید:

```powershell
git clone https://github.com/meicamghe/FDMX.git
cd FDMX
```

یا از صفحه GitHub گزینه **Code → Download ZIP** را انتخاب و فایل را استخراج کنید.

### ۳. ساخت محیط مجازی و نصب وابستگی

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install --upgrade pip
py -m pip install PySide6
```

اگر فعال‌سازی محیط مجازی در PowerShell مسدود بود، از CMD استفاده کنید:

```bat
.venv\Scripts\activate.bat
py -m pip install PySide6
```

### ۴. اجرای برنامه

```powershell
py FDMX_v6_11.py
```

برای اجرای تم Ubuntu در ویندوز:

```powershell
py ubuntu.py
```

## نصب و اجرا در Ubuntu

نسخه Ubuntu برای آزمایش ارائه شده و سازگاری کامل آن روی همه توزیع‌ها تضمین نشده است.

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip git
git clone https://github.com/meicamghe/FDMX.git
cd FDMX
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install PySide6
python ubuntu.py
```

اگر برنامه اجرا نشد، آن را از Terminal اجرا کنید و متن کامل خطا را نگه دارید.

## شروع دانلود

۱. برنامه را اجرا کنید.
۲. لینک مستقیم HTTP یا HTTPS را در کادر URL وارد کنید.
۳. مسیر ذخیره فایل و تنظیمات دانلود را انتخاب کنید.
۴. دانلود را شروع کنید.
۵. برای مشاهده جزئیات هر دانلود، روی مورد مربوطه دوبار کلیک کنید؛ کنترل‌های توقف موقت، ادامه، لغو و تلاش مجدد در نسخه‌های پشتیبانی‌کننده نمایش داده می‌شوند.

توجه: عملکرد چنداتصالی و ادامه دانلود به پشتیبانی سرور مقصد از درخواست‌های Range وابسته است. بعضی سرورها دانلود چندبخشی یا Resume را محدود می‌کنند.

## اتصال افزونه مرورگر

افزونه‌ها لینک‌ها را از طریق سرویس محلی برنامه به آدرس `127.0.0.1:38471` ارسال می‌کنند. ابتدا خود برنامه را اجرا کنید.

### Chrome

۱. آدرس `chrome://extensions` را باز کنید.
۲. **Developer mode** را فعال کنید.
۳. روی **Load unpacked** کلیک کنید.
۴. پوشه `browser-extensions/chrome` را انتخاب کنید.

### Firefox

۱. آدرس `about:debugging#/runtime/this-firefox` را باز کنید.
۲. روی **Load Temporary Add-on** کلیک کنید.
۳. فایل `browser-extensions/firefox/manifest.json` را انتخاب کنید.

افزونه Firefox در این روش موقت است و با بستن مرورگر حذف می‌شود. برای انتشار دائمی باید افزونه توسط Mozilla امضا شود.

### روش استفاده

روی لینک دانلود در صفحه وب راست‌کلیک کنید و گزینه **Download link with FDMX** را بزنید؛ یا Popup افزونه را باز کنید و نشانی صفحه جاری را ارسال کنید.

اگر پیام عدم اتصال دریافت شد:
- مطمئن شوید FDMX باز است.
- نسخه برنامه باید Browser Bridge داشته باشد.
- پورت محلی `38471` نباید توسط برنامه دیگری اشغال شده باشد.
- این سرویس را روی شبکه عمومی یا آدرس `0.0.0.0` در دسترس قرار ندهید.

## فایل‌های داده و حریم خصوصی

اطلاعات تاریخچه و وظایف برنامه در پوشه `.fdmx` داخل مسیر Home کاربر ذخیره می‌شوند؛ از جمله فایل‌های `history.json` و `tasks.json`. لینک‌های دانلود ممکن است دارای توکن خصوصی باشند؛ قبل از ارسال گزارش خطا، اطلاعات حساس را حذف کنید.

## رفع مشکلات رایج

| مشکل | راهکار اولیه |
|---|---|
| خطای `No module named PySide6` | محیط مجازی را فعال و `py -m pip install PySide6` را اجرا کنید. |
| برنامه باز نمی‌شود | از ترمینال اجرا کنید و متن کامل خطا را بررسی کنید. |
| افزونه به برنامه وصل نمی‌شود | برنامه را باز کنید و پورت محلی 38471 را بررسی کنید. |
| Resume کار نمی‌کند | ممکن است سرور مقصد از Range Request پشتیبانی نکند یا لینک منقضی شده باشد. |
| Firefox افزونه را تأییدنشده نشان می‌دهد | برای تست از نصب موقت استفاده کنید؛ انتشار دائمی نیازمند امضای Mozilla است. |
