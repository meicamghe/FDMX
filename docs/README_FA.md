# راهنمای GNS Downloader — نسخه 6.53

GNS Downloader یک دانلودمنیجر دسکتاپ مبتنی بر Python و PySide6 است.

## نسخه 6.53

- نسخه 6.53 قابلیت انتقال خودکار دانلودهای مرورگر به برنامه را از طریق افزونه و پروتکل `gnsdownloader://` اضافه می‌کند. در صورت بسته بودن برنامه، پروتکل ثبت‌شده در نصب‌کننده آن را اجرا می‌کند.
- افزونه نسخه 1.3.0 در صفحات دارای رسانه مستقیم پیشنهاد دانلود نمایش می‌دهد و برای YouTube کیفیت‌های موجود و حالت صوت-only را از موتور `yt-dlp` برنامه دریافت می‌کند.
- از منوی **Tools → Install browser extensions…** راهنمای نصب افزونه Firefox و Chrome در دسترس است. Firefox از فهرست رسمی AMO نصب می‌شود؛ Chrome تا زمان انتشار در Chrome Web Store با Developer mode و گزینه Load unpacked نصب می‌شود.

- دانلود Artifactهای GitHub Actions ابتدا بدون توکن امتحان می‌شود؛ فقط اگر GitHub دسترسی را رد کند، درخواست توکن نمایش داده می‌شود.
- توکن در فایل‌های وظایف و تاریخچه ذخیره نمی‌شود و هنگام انتقال به دامنه دیگر در هدر درخواست ارسال نخواهد شد.
- دانلودهای تکمیل‌شده بر اساس جدیدترین زمان پایان در بالای فهرست قرار می‌گیرند و با اولین کلیک Start دانلود آغاز می‌شود.

نسخه **6.53 منتشر شده و آخرین نسخه رسمی برنامه است**. فایل‌های اجرایی Windows Setup، Windows Portable و بسته Ubuntu/Debian اکنون مستقیماً در صفحه انتشار رسمی قرار دارند. فایل اصلی و مرجع برنامه `FDMX_v6_50.py` است.

- دانلود ویدئو و صدا از YouTube با کتابخانه `yt-dlp` انجام می‌شود. برای ادغام بهترین کیفیت تصویر و صدا به FFmpeg نیاز است؛ دانلود فقط صوت به FFmpeg نیاز ندارد.
- انواع پروکسی HTTP، HTTPS، SOCKS4، SOCKS4a، SOCKS5 و SOCKS5h پشتیبانی می‌شوند. در بسته‌های آماده، پشتیبانی SOCKS با PySocks همراه برنامه بسته‌بندی می‌شود. آدرس پروکسی باید میزبان و پورت معتبر داشته باشد؛ مسیر، Query و Fragment در آدرس پذیرفته نمی‌شوند تا اشتباهاً نادیده گرفته نشوند.
- آپدیتر فقط انتشارهای پایدار با تگ نسخه عددی معتبر را بررسی می‌کند، بالاترین نسخه را انتخاب می‌کند و اندازه فایل و در صورت وجود SHA-256 اعلام‌شده در GitHub را اعتبارسنجی می‌کند. لغو دانلود فایل نصب‌کننده نیز پشتیبانی می‌شود.
- نسخه‌های Portable و اجرای مستقیم از سورس، صفحه انتشار GitHub را باز می‌کنند؛ نصب خودکار Setup برای نسخه نصب‌شده ویندوز در نظر گرفته شده است.

تست‌های آفلاین رگرسیون و بررسی بسته‌بندی ویندوز و لینوکس برای نسخه 6.53 در CI با موفقیت تکمیل شده‌اند. این تست‌ها جایگزین آزمایش واقعی دانلود از YouTube، اتصال پروکسی و تست دستی رابط گرافیکی نیستند.

### نصب سریع: بسته آماده لینوکس

بسته آماده **DEB برای معماری AMD64** مستقیماً از [انتشار رسمی 6.53](https://github.com/meicamghe/FDMX/releases/tag/6.53) قابل دریافت است. فایل را دانلود و با APT نصب کنید؛ برای این روش به Git، Python، محیط مجازی یا Wine نیازی ندارید.

معماری سیستم را بررسی کنید؛ خروجی باید `amd64` باشد:

```bash
dpkg --print-architecture
```

دانلود و نصب بسته (APT وابستگی‌های اعلام‌شده را خودکار نصب می‌کند):

```bash
sudo apt install ./GNS-Downloader-6.53-amd64.deb
```

پس از نصب، برنامه را از منوی برنامه‌های دسکتاپ اجرا کنید یا در ترمینال دستور `gns-downloader` را بزنید. بسته روی Ubuntu 22.04 با معماری AMD64 ساخته و تست نصب و اجرا شده است. فعلاً AppImage و Flatpak ارائه نمی‌شوند.

### روش جایگزین: اجرا از سورس (نیازمند Git و Python 3.12)

### ۱. نصب کتابخانه‌های موردنیاز سیستم

در ترمینال Ubuntu یا Debian اجرا کنید:

```bash
sudo apt update
sudo apt install -y git libegl1 libgl1 libxkbcommon0 libdbus-1-3
```

### ۲. بررسی و نصب Python 3.12

نسخه **Python 3.12** نسخه‌ای است که در CI پروژه استفاده و آزمایش می‌شود. ابتدا بررسی کنید نصب باشد:

```bash
python3.12 --version
```

اگر نصب نیست، روش متناسب با توزیع خود را اجرا کنید:

**Ubuntu 24.04 LTS** (نسخه Python 3.12 در مخزن رسمی اوبونتو موجود است):

```bash
sudo apt update
sudo apt install -y python3.12 python3.12-venv python3-pip
```

**Ubuntu 22.04 یا Debian 12:** مخزن استاندارد این نسخه‌ها Python 3.12 را به‌عنوان مفسر پیش‌فرض ارائه نمی‌کند. مدیر مستقل Python با نام `uv` را نصب کنید و با آن Python 3.12 را دریافت کنید:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
uv python install 3.12
```

اگر دستور `uv` شناخته نشد، یک ترمینال جدید باز کنید.

### ۳. دریافت سورس و ساخت محیط مجازی

ابتدا سورس را دریافت کنید:

```bash
git clone https://github.com/meicamghe/FDMX.git
cd FDMX
```

در Ubuntu 24.04 محیط مجازی را با دستور زیر بسازید:

```bash
python3.12 -m venv .venv
```

در Ubuntu 22.04 یا Debian 12 از دستور زیر استفاده کنید:

```bash
uv venv --python 3.12 --seed .venv
```

سپس محیط مجازی را فعال و وابستگی برنامه را نصب کنید:

```bash
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install PySide6-Essentials yt-dlp PySocks
```

محیط مجازی باعث می‌شود وابستگی‌های برنامه از Python و بسته‌های سیستمی جدا بمانند.

### ۴. اجرای برنامه

```bash
python ubuntu.py
```

همچنین می‌توانید فایل اصلی را مستقیماً اجرا کنید:

```bash
python FDMX_v6_50.py
```

برای اجرای دوباره در ترمینال جدید، وارد پوشه پروژه شوید و محیط مجازی را فعال کنید:

```bash
cd FDMX
source .venv/bin/activate
python ubuntu.py
```

### رفع خطاهای رایج

- اگر Qt درباره افزونه `xcb` یا کتابخانه اشتراکیِ گم‌شده خطا داد، کتابخانه‌های تکمیلی زیر را نصب و برنامه را دوباره اجرا کنید:

```bash
sudo apt install -y libxcb-cursor0 libxcb-xinerama0 libxcb-icccm4 libxcb-keysyms1 libxcb-render-util0
```

- برنامه باید در نشست گرافیکی دسکتاپ اجرا شود؛ اجرای آن از SSH متنی و بدون نمایشگر گرافیکی معمولاً پنجره‌ای نشان نمی‌دهد.
- برای نصب مجدد وابستگی Python، درحالی‌که محیط مجازی فعال است اجرا کنید:

```bash
python -m pip install --force-reinstall PySide6-Essentials
```

## ساخت بسته‌های ویندوز

ساخت فایل اجرایی ویندوز باید روی ویندوز انجام شود؛ PyInstaller ابزار کامپایل میان‌سکویی (Cross-Compile) نیست. برای ساخت به Python 3.12، PySide6-Essentials، PyInstaller، Pillow و Inno Setup نیاز دارید. روش بازتولیدپذیر ساخت و آزمون‌های دود (Smoke Test) در [Workflow ساخت ویندوز در GitHub Actions](../.github/workflows/build-fdmx-windows.yml) تعریف شده است.

## یکپارچگی مرورگر در نسخه 6.53

نسخه 6.53 شامل افزونه همراه مرورگر با شماره 1.3.0 و پل ارتباطی متناظر در برنامه دسکتاپ است:

- لینک مستقیم فایل‌ها و دانلودهای مرورگر به‌طور خودکار به GNS Downloader سپرده می‌شوند. اگر برنامه بسته باشد، پروتکل ثبت‌شده `gnsdownloader://` آن را اجرا کرده و نشانی را به صف دانلود اضافه می‌کند.
- در Chrome و Firefox روی لینک راست‌کلیک کنید و گزینه **Download with GDM** را انتخاب کنید؛ آیکون افزونه نیز در نوار مرورگر قرار دارد.
- در صفحاتی که نشانی مستقیم صوت یا ویدئو ارائه می‌کنند، پیشنهاد دریافت رسانه نمایش داده می‌شود. در YouTube موتور `yt-dlp` برنامه وضوح‌های ویدئویی و نرخ بیت صوتی موجود، از جمله حالت فقط صوت، را استخراج می‌کند.
- گزینه **Tools → Install browser extensions…** در برنامه دسکتاپ راهنمای نصب از طریق Firefox AMO و نصب Chrome با Developer mode و گزینه Load unpacked را نمایش می‌دهد.
- فهرست موجود Firefox AMO و شناسه Gecko یعنی `fdmx-browser@gns.local` برای به‌روزرسانی در همان فهرست حفظ شده‌اند.

افزونه نسخه 1.3.0 از طریق [گردش‌کار CI ساخت افزونه مرورگر](https://github.com/meicamghe/FDMX/actions/workflows/build-browser-extensions.yml) ساخته می‌شود.

### دریافت و نصب افزونه Chrome

1. [گردش‌کار ساخت افزونه مرورگر](https://github.com/meicamghe/FDMX/actions/workflows/build-browser-extensions.yml) را باز کنید و آخرین اجرای موفق را انتخاب کنید.
2. فایل Artifact با نام `GNS-Downloader-browser-extensions-1.3.0` را دریافت و ZIP آن را استخراج کنید.
3. فایل `GNS-Downloader-Chrome-1.3.0.zip` را نیز استخراج کنید.
4. در نوار نشانی Chrome عبارت `chrome://extensions` را باز کنید و **Developer mode** را فعال کنید.
5. روی **Load unpacked** کلیک کنید و پوشه استخراج‌شده افزونه Chrome را که فایل `manifest.json` در آن قرار دارد انتخاب کنید.

### نصب یا به‌روزرسانی Firefox

از [فهرست رسمی GNS Download Manager در Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/gns-download-manager/) استفاده کنید. فایل XPI نسخه 1.3.0 برای به‌روزرسانی همان فهرست در نظر گرفته شده است. برای آزمایش موقت در نسخه Developer Edition فایرفاکس، مسیر `about:debugging#/runtime/this-firefox` و گزینه **Load Temporary Add-on** را باز کنید.

## افزونه مرورگر GNS Downloader نسخه 1.3.0

نسخه افزونه مرورگر **1.3.0** برای نسخه دسکتاپ **6.53** منتشر شده است.

- کلیک روی لینک فایل و دانلودهای عادی HTTP/HTTPS به‌صورت خودکار به GNS منتقل می‌شود؛ اگر برنامه بسته باشد، پروتکل `gnsdownloader://` برنامه را اجرا می‌کند.
- منوی راست‌کلیک Chrome و Firefox گزینه **Download with GDM** را همراه آیکون برنامه نشان می‌دهد.
- صفحات دارای ویدئو یا صوت مستقیم، پنل پیشنهاد دانلود نمایش می‌دهند.
- در YouTube، افزونه کیفیت‌های تصویری و bitrateهای صوتی موجود و گزینه صوت-only را از موتور `yt-dlp` برنامه می‌گیرد تا کاربر انتخاب کند.
- نشست GitHub حفظ شده و کوکی‌ها خوانده یا ذخیره نمی‌شوند.

### نصب در Firefox

افزونه منتشرشده و تأییدشده: [GNS Download Manager در Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/gns-download-manager/).

نسخه 1.3.0 باید به‌عنوان به‌روزرسانی همان فهرست AMO ارسال شود؛ شناسه Gecko موجود `fdmx-browser@gns.local` حفظ شده است. حداقل Firefox 140 لازم است. به‌دلیل ارسال آدرس لینک‌ها و دانلودها به برنامه دسکتاپ محلی، مجوز `websiteActivity` در manifest اعلام شده است؛ آدرس‌ها به سرویس ابری GNS ارسال نمی‌شوند. برای تست موقت در Firefox Developer Edition از `about:debugging#/runtime/this-firefox` و **Load Temporary Add-on** استفاده کنید.

### نصب در Chrome

1. [Workflow ساخت افزونه‌ها](https://github.com/meicamghe/FDMX/actions/workflows/build-browser-extensions.yml) را باز کنید.
2. آخرین اجرای موفق را انتخاب و Artifact با نام `GNS-Downloader-browser-extensions-1.3.0` را دانلود کنید.
3. ZIP اصلی را استخراج کنید؛ سپس `GNS-Downloader-Chrome-1.3.0.zip` را نیز استخراج کنید.
4. در Chrome وارد `chrome://extensions` شوید و **Developer mode** را روشن کنید.
5. روی **Load unpacked** بزنید و پوشه‌ای را انتخاب کنید که فایل `manifest.json` افزونه داخل آن است.

برای نصب افزونه، برنامه دسکتاپ **GNS Downloader 6.53** باید نصب باشد. اولین بار که مرورگر پروتکل خارجی برنامه را اجرا می‌کند ممکن است تأیید باز کردن برنامه را بخواهد.

## افزونه مرورگر و حریم خصوصی

سورس افزونه‌های Chrome و Firefox در پوشه `browser-extensions/` قرار دارد. سرویس ارتباط دسکتاپ فقط روی 127.0.0.1:38471 گوش می‌دهد؛ آن را روی شبکه محلی یا اینترنت عمومی منتشر نکنید.

وظایف و تاریخچه دانلود در پوشه `.fdmx` داخل پروفایل کاربر ذخیره می‌شوند. لینک دانلود ممکن است توکن خصوصی داشته باشد؛ پیش از ارسال لاگ، اطلاعات حساس URL را حذف کنید.

## حریم خصوصی و ارتباط افزونه با برنامه

افزونه مرورگر برای تحویل نشانی دانلود به برنامه دسکتاپ از پل محلی استفاده می‌کند. سرویس پل فقط روی رابط Loopback یعنی `127.0.0.1:38471` گوش می‌دهد؛ آن را روی شبکه محلی یا رابط عمومی در دسترس قرار ندهید.

کوکی‌های مرورگر برای انتقال دانلود صادر یا ذخیره نمی‌شوند. اطلاعات احراز هویت Artifactهای GitHub فقط در صورت نیاز به‌کار می‌روند و در فایل وظایف یا تاریخچه ذخیره نمی‌شوند. نشانی‌های دانلود ممکن است حاوی توکن خصوصی و موقت باشند؛ پیش از اشتراک‌گذاری گزارش‌ها و لاگ‌ها، این اطلاعات را حذف کنید.

## آزمون و بررسی کد

برای بررسی خطاهای نحوی فایل‌های ورودی اصلی و اجرای آزمون‌های رگرسیون YouTube از دستورات زیر استفاده کنید:

```bash
python -m py_compile FDMX_v6_50.py ubuntu.py
python -m unittest discover -s tests -p "test_youtube_integration_regressions.py" -v
```

این آزمون‌های آفلاین جایگزین آزمایش زنده دانلود از YouTube، بررسی اتصال واقعی پروکسی یا آزمون دستی رابط گرافیکی نیستند.

## تست‌ها

```bash
python -m py_compile FDMX_v6_50.py ubuntu.py
python -m unittest discover -s tests -p "test_youtube_integration_regressions.py" -v
```

فایل اصلی و مرجع برنامه فعلی `FDMX_v6_50.py` است؛ فایل‌های نسخه ۵ از شاخه اصلی مخزن حذف شده‌اند. فایل `ubuntu.py` نقطه شروع اجرای نسخه لینوکس است.
