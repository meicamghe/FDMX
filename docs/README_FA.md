# راهنمای GNS Downloader نسخه 6.39

GNS Downloader یک دانلودمنیجر دسکتاپ برای ویندوز است که با Python و PySide6 ساخته شده است.

## وضعیت نسخه فعلی

- **شماره نسخه:** 6.39
- **فایل اصلی برنامه:** `FDMX_v6_36.py`
- **سیستم‌عامل هدف:** Windows 10/11 نسخه ۶۴ بیتی
- **ظاهر برنامه:** تم ثابت Windows 11 Fluent؛ تب انتخاب تم و Theme Studio وجود ندارد.
- **Plugin Manager در رابط کاربری برنامه وجود ندارد.**

## امکانات اصلی

- دانلود HTTP و HTTPS با چند اتصال هم‌زمان
- توقف، ادامه، لغو و تلاش مجدد دانلود
- صف دانلود و ذخیره وضعیت وظایف
- پنجره جزئیات مستقل برای هر دانلود، همراه با درصد پیشرفت و اطلاعات قطعه‌های دانلود؛ پس از پایان موفق، دکمه‌های عملیاتی به **Open** و **Close** تغییر می‌کنند و کنترل‌های حین دانلود پنهان می‌شوند.
- زمان‌بندی دانلود و محدودیت سرعت
- تاریخچه و گزارش آماری CSV/JSON
- دریافت لینک از افزونه مرورگر از طریق ارتباط محلی `127.0.0.1:38471`
- تعیین عملیات بعد از پایان برای هر دانلود به‌صورت مستقل: هیچ‌کاری انجام نشود، خاموش‌کردن ویندوز، خروج از حساب یا Hibernate
- نمایش واضح‌تر وضعیت فعال و غیرفعال دکمه‌ها
- موتور هوشمند تشخیص سرعت: ابتدای دانلود یک بازه واقعی از فایل را اندازه‌گیری می‌کند، سرعت اولیه را تخمین می‌زند و متناسب با اندازه فایل و سرعت به‌دست‌آمده، تعداد پارت‌ها را بین ۱، ۲، ۴ و حداکثر ۸ انتخاب می‌کند. نقشه بازه‌های بایتی و تعداد پارت‌ها ذخیره می‌شوند تا ادامه‌دادن دانلود پس از Pause یا اجرای مجدد برنامه با همان تقسیم‌بندی انجام شود.

موتور تطبیقی در ابتدای دانلود تعداد پارت‌ها را انتخاب می‌کند و در طول همان انتقال، بازه‌های بایتی را دوباره تقسیم‌بندی نمی‌کند؛ این کار برای جلوگیری از تداخل داده‌ها و حفظ امکان Resume است. اگر سرور از HTTP Range پشتیبانی نکند، دانلود با یک اتصال انجام می‌شود.

## تنظیم عملیات بعد از دانلود

برای هر فایل، پنجره جزئیات همان دانلود را باز کنید (روی ردیف دانلود دوبار کلیک کنید). در قسمت **After this download finishes** ابتدا گزینه را فعال و سپس عملیات دلخواه را انتخاب کنید.

این تنظیم فقط برای همان دانلود ذخیره می‌شود و روی دانلودهای دیگر اثری ندارد. عملیات خاموش‌کردن، خروج از حساب و Hibernate فقط در ویندوز اجرا می‌شوند و پس از تکمیل موفق همان دانلود انجام خواهند شد. در انتخاب این گزینه‌ها دقت کنید؛ ممکن است کارهای باز دیگر شما متوقف شوند.

## دریافت نسخه ویندوز

پس از موفقیت Workflow ساخت ویندوز، دو Artifact جداگانه در GitHub Actions منتشر می‌شوند:

- **[دریافت نسخه Portable ZIP — نسخه 6.39](https://github.com/meicamghe/FDMX/actions)** — فایل ZIP را استخراج و `GNS Downloader.exe` را اجرا کنید.
- **[دریافت نسخه Setup — نسخه 6.39](https://github.com/meicamghe/FDMX/actions)** — فایل نصب را اجرا کنید تا برنامه نصب و میانبرها ایجاد شوند.

در مخزن GitHub وارد تب **Actions** شوید و آخرین اجرای موفق **Build GNS Downloader Windows packages** را باز کنید. Artifact مربوط به Portable و Setup جدا از هم نمایش داده می‌شوند. مدت نگهداری Artifactها ۱۴ روز است؛ این فایل‌ها GitHub Release دائمی نیستند.

## اجرای برنامه از روی سورس در ویندوز

Python 3.12 را نصب کنید و در PowerShell، داخل پوشه پروژه اجرا کنید:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install PySide6-Essentials
python FDMX_v6_36.py
```

## ساخت نسخه Portable و Setup

ساخت فایل‌های اجرایی ویندوز باید روی خود ویندوز انجام شود؛ PyInstaller ابزار Cross-Compile نیست. برای ساخت به Python 3.12، PySide6-Essentials، PyInstaller، Pillow و Inno Setup نیاز دارید.

روش استاندارد و قابل تکرار، اجرای Workflow زیر است:

1. وارد مخزن GitHub شوید.
2. تب **Actions** را باز کنید.
3. Workflow با نام **Build GNS Downloader Windows packages** را انتخاب کنید.
4. روی **Run workflow** بزنید یا با Push تغییرات مرتبط، اجازه دهید خودکار اجرا شود.
5. پس از موفقیت، Artifactهای Portable و Setup را جداگانه دریافت کنید.

فایل نصب از اسکریپت `installer/FDMX.iss` ساخته می‌شود. نسخه Portable یک ZIP از پوشه کامل برنامه است؛ فایل اجرایی را از داخل همان پوشه استخراج‌شده اجرا کنید.

## افزونه‌های مرورگر

سورس افزونه‌های Chrome و Firefox در پوشه `browser-extensions/` قرار دارد. سرویس ارتباط دسکتاپ فقط روی `127.0.0.1:38471` گوش می‌دهد؛ آن را روی شبکه محلی یا اینترنت عمومی منتشر نکنید. افزونه موقت Firefox پس از بستن مرورگر باید دوباره بارگذاری شود.

## محل نگهداری اطلاعات

وظایف و تاریخچه دانلود در پوشه `.fdmx` داخل پروفایل کاربر ذخیره می‌شوند. لینک دانلود ممکن است حاوی توکن خصوصی باشد؛ پیش از ارسال گزارش یا لاگ، اطلاعات حساس URL را حذف کنید.

## تست‌های رگرسیون

از ریشه مخزن اجرا کنید:

```powershell
python -m py_compile FDMX_v6_36.py
python tests/test_gns_downloader_regressions.py
```

## نکته درباره فایل‌های قدیمی مخزن

فایل‌های نسخه‌های قبلی و سورس جداگانه Plugin SDK برای حفظ تاریخچه توسعه در مخزن باقی مانده‌اند؛ اما فایل اجرایی فعلی GNS Downloader همین `FDMX_v6_36.py` است و SDK جداگانه در بسته ویندوز قرار نمی‌گیرد.

پیش از توزیع مجدد سورس یا فایل‌های اجرایی، [اطلاعیه مجوز پروژه](../LICENSE-NOTICE.md) را مطالعه کنید.
