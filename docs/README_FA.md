# راهنمای GNS Downloader نسخه 6.42

GNS Downloader یک دانلودمنیجر دسکتاپ مبتنی بر Python و PySide6 است.

## شاخه توسعه نسخه 6.50 (هنوز منتشر نشده)

شاخه `release/6.50-finalization` شامل سورس در حال توسعه نسخه **6.50** با فایل اصلی `FDMX_v6_50.py` است. آخرین انتشار عمومی GitHub همچنان **نسخه 6.42** است؛ commitهای شاخه توسعه تا زمان انتشار یک نسخه پایدار، توسط آپدیتر داخل برنامه قابل مشاهده نیستند.

- دانلود ویدئو و صدا از YouTube با کتابخانه `yt-dlp` انجام می‌شود. برای ادغام بهترین کیفیت تصویر و صدا به FFmpeg نیاز است؛ دانلود فقط صوت به FFmpeg نیاز ندارد.
- انواع پروکسی HTTP، HTTPS، SOCKS4، SOCKS4a، SOCKS5 و SOCKS5h پشتیبانی می‌شوند. در بسته‌های آماده، پشتیبانی SOCKS با PySocks همراه برنامه بسته‌بندی می‌شود. آدرس پروکسی باید میزبان و پورت معتبر داشته باشد؛ مسیر، Query و Fragment در آدرس پذیرفته نمی‌شوند تا اشتباهاً نادیده گرفته نشوند.
- آپدیتر فقط انتشارهای پایدار با تگ نسخه عددی معتبر را بررسی می‌کند، بالاترین نسخه را انتخاب می‌کند و اندازه فایل و در صورت وجود SHA-256 اعلام‌شده در GitHub را اعتبارسنجی می‌کند. لغو دانلود فایل نصب‌کننده نیز پشتیبانی می‌شود.
- نسخه‌های Portable و اجرای مستقیم از سورس، صفحه انتشار GitHub را باز می‌کنند؛ نصب خودکار Setup برای نسخه نصب‌شده ویندوز در نظر گرفته شده است.

تست‌های آفلاین رگرسیون و بررسی بسته‌بندی ویندوز و لینوکس برای این شاخه تعریف شده‌اند. این تست‌ها جایگزین آزمایش واقعی دانلود از YouTube، اتصال پروکسی و تست دستی رابط گرافیکی نیستند.

## نصب و اجرای لینوکس (Ubuntu و Debian)

بسته نصب بومی **`.deb` مخصوص Ubuntu و Debian** برای نسخه 6.42 ساخته، تست نصب و اجرا شده و به انتشار عمومی GitHub پیوست شده است. فعلاً AppImage و Flatpak ارائه نمی‌شوند. برای اجرای برنامه به Wine نیاز ندارید؛ نسخه لینوکس از همان سورس اصلی ساخته می‌شود و تم Ubuntu Yaru را خودکار انتخاب می‌کند.

### نصب سریع: بسته آماده لینوکس

نسخه 6.42 شامل بسته نصب آماده **DEB برای معماری AMD64** است. برای استفاده معمول، این روش پیشنهاد می‌شود و به Git، Python، محیط مجازی یا Wine نیازی ندارد.

معماری سیستم را بررسی کنید؛ خروجی باید `amd64` باشد:

```bash
dpkg --print-architecture
```

دانلود و نصب بسته (APT وابستگی‌های اعلام‌شده را خودکار نصب می‌کند):

```bash
curl -fL "https://github.com/meicamghe/FDMX/releases/download/v6.42/GNS-Downloader-6.42-amd64.deb" -o /tmp/GNS-Downloader-6.42-amd64.deb
sudo apt install /tmp/GNS-Downloader-6.42-amd64.deb
```

پس از نصب، برنامه را از منوی برنامه‌های دسکتاپ اجرا کنید یا در ترمینال دستور `gns-downloader` را بزنید. بسته روی Ubuntu 22.04 با معماری AMD64 ساخته و تست نصب و اجرا شده است. فعلاً AppImage و Flatpak ارائه نمی‌شوند.

### روش جایگزین: اجرا از سورس (نیازمند Git و Python 3.12)

### ۱. نصب کتابخانه‌های موردنیاز سیستم

در ترمینال Ubuntu یا Debian اجرا کنید:

```bash
sudo apt update
sudo apt install -y git libegl1 libgl1 libxkbcommon0 libdbus-1-3
```

### ۲. بررسی و نصب Python 3.12

نسخه **Python 3.12** نسخه‌ای است که در CI پروژه استفاده و آزمایش می‌شود. ابتدا بررسی کنید نصب باشد:

```bash
python3.12 --version
```

اگر نصب نیست، روش متناسب با توزیع خود را اجرا کنید:

**Ubuntu 24.04 LTS** (نسخه Python 3.12 در مخزن رسمی اوبونتو موجود است):

```bash
sudo apt update
sudo apt install -y python3.12 python3.12-venv python3-pip
```

**Ubuntu 22.04 یا Debian 12:** مخزن استاندارد این نسخه‌ها Python 3.12 را به‌عنوان مفسر پیش‌فرض ارائه نمی‌کند. مدیر مستقل Python با نام `uv` را نصب کنید و با آن Python 3.12 را دریافت کنید:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
uv python install 3.12
```

اگر دستور `uv` شناخته نشد، یک ترمینال جدید باز کنید.

### ۳. دریافت سورس و ساخت محیط مجازی

ابتدا سورس را دریافت کنید:

```bash
git clone https://github.com/meicamghe/FDMX.git
cd FDMX
```

در Ubuntu 24.04 محیط مجازی را با دستور زیر بسازید:

```bash
python3.12 -m venv .venv
```

در Ubuntu 22.04 یا Debian 12 از دستور زیر استفاده کنید:

```bash
uv venv --python 3.12 --seed .venv
```

سپس محیط مجازی را فعال و وابستگی برنامه را نصب کنید:

```bash
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install PySide6-Essentials
```

محیط مجازی باعث می‌شود وابستگی‌های برنامه از Python و بسته‌های سیستمی جدا بمانند.

### ۴. اجرای برنامه

```bash
python ubuntu.py
```

همچنین می‌توانید فایل اصلی را مستقیماً اجرا کنید:

```bash
python FDMX_v6_50.py
```

برای اجرای دوباره در ترمینال جدید، وارد پوشه پروژه شوید و محیط مجازی را فعال کنید:

```bash
cd FDMX
source .venv/bin/activate
python ubuntu.py
```

### رفع خطاهای رایج

- اگر Qt درباره افزونه `xcb` یا کتابخانه اشتراکیِ گم‌شده خطا داد، کتابخانه‌های تکمیلی زیر را نصب و برنامه را دوباره اجرا کنید:

```bash
sudo apt install -y libxcb-cursor0 libxcb-xinerama0 libxcb-icccm4 libxcb-keysyms1 libxcb-render-util0
```

- برنامه باید در نشست گرافیکی دسکتاپ اجرا شود؛ اجرای آن از SSH متنی و بدون نمایشگر گرافیکی معمولاً پنجره‌ای نشان نمی‌دهد.
- برای نصب مجدد وابستگی Python، درحالی‌که محیط مجازی فعال است اجرا کنید:

```bash
python -m pip install --force-reinstall PySide6-Essentials
```

## اجرای برنامه از سورس در ویندوز

Python **3.12** را نصب کنید و در PowerShell، در پوشه پروژه اجرا کنید:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install PySide6-Essentials
python FDMX_v6_50.py
```

## ساخت بسته‌های ویندوز

ساخت فایل اجرایی ویندوز باید روی ویندوز انجام شود؛ PyInstaller ابزار Cross-Compile نیست. برای ساخت به Python 3.12، PySide6-Essentials، PyInstaller، Pillow و Inno Setup نیاز دارید. روش استاندارد ساخت و تست در Workflow گیت‌هاب تعریف شده است.

## افزونه مرورگر و حریم خصوصی

سورس افزونه‌های Chrome و Firefox در پوشه `browser-extensions/` قرار دارد. سرویس ارتباط دسکتاپ فقط روی 127.0.0.1:38471 گوش می‌دهد؛ آن را روی شبکه محلی یا اینترنت عمومی منتشر نکنید.

وظایف و تاریخچه دانلود در پوشه `.fdmx` داخل پروفایل کاربر ذخیره می‌شوند. لینک دانلود ممکن است توکن خصوصی داشته باشد؛ پیش از ارسال لاگ، اطلاعات حساس URL را حذف کنید.
